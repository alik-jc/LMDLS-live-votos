# 🏰 La Mansión - Votación en Vivo

Visualizador en tiempo real y plataforma de resultados para **La Mansión de los Streamers** de Westcol.

> **🎉 ESTADO ACTUAL: EVENTO FINALIZADO**
> Los ganadores han sido anunciados y la votación ha concluido.

## 🚀 Características Principales

- **🏆 Showcase de Ganadores:** Sección destacada celebrando a los campeones (Natalia Es Mejor y Edits De Mierda).
- **🤝 Patrocinadores Oficiales:** Integración visual de partners como Stake, Dynamo, Amper y Humo Barriles.
- **⏱️ Tiempo Real:** Sistema optimizado para actualizaciones de votos (durante el evento).
- **🎨 UI/UX Premium:** 
  - Diseño moderno con soporte para **Modo Oscuro/Claro**.
  - Avatares personalizados y actualizados para todos los participantes.
  - Animaciones fluidas y diseño responsive.
- **📺 Integración con Kick:** Reproductor embebido y enlaces directos a los canales de los streamers.
- **🤖 Detector de Bots:** Análisis inteligente para identificar patrones de votación sospechosos.

## 🛠️ Tecnologías

Desarrollado con un stack moderno para máximo rendimiento:
- **React + Vite:** Core de la aplicación.
- **Tailwind CSS:** Estilizado avanzado y responsive.
- **TypeScript:** Tipado estático para mayor robustez.
- **Lucide React:** Iconografía moderna.

## 📂 Estructura del Proyecto

- `src/components`: Componentes de UI (Hero, Leaderboard, EventFinishedLanding, etc.).
- `src/data`: Datos estáticos y de fallback.
- `src/utils`: Constantes, helpers y mapeos (Avatares, Redes Sociales).

## 🏁 Cómo iniciar

1.  Clona el repositorio.
2.  Instala dependencias:
    ```bash
    npm install
    ```
3.  Configura las variables de entorno (ver `.env.example`).
4.  Inicia el servidor de desarrollo:
    ```bash
    npm run dev
    ```
